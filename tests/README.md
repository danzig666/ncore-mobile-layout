# Mobile layout regression checks

Run `node tests/preview-server.js` from the repository root, then open `http://127.0.0.1:8765/torrents.php` in a browser. This dependency-free fixture reproduces native and aNi torrent wrappers, site event handlers, filters, AJAX panels, and a bookmark dialog using synthetic data. It loads the actual userscript. Toolbar controls mock Tampermonkey preferences and pointer detection; they are not production UI.

Check both the native page and the aNi page (`Toggle aNi`):

1. At 320px and 390px CSS viewport width, `Auto` plus `Mouse pointer` must leave the original page untouched. `Touch pointer` must activate mobile controls. `Mobile` should also activate with a mouse, and `Desktop` must restore the original page.
2. At 761px and wider, mobile controls must be absent even in `Mobile` mode. Resize from mobile to desktop and back: original controls and event handlers must survive, without duplicated controls. Compare the container DOM before activation and after deactivation; it must be identical when no site state has changed.
3. Check that titles, translated titles, metadata, and bookmarks do not overlap, and that the mobile document has no horizontal overflow. Size, category/resolution, seed/leech counts, IMDb rating, and the full upload date/time must remain readable when collapsed. Rows must be shorter than the prior layout: there must be no separate Kibontás/Részletek button row. The original bookmark must stay visible with a 44×44px target beside the metadata/date block. Expanding must not show duplicate upload/size blocks or the separate download-count or uploader-name fields. Expanded cards must retain their native panel actions, including Részletek.
4. Open filters. All concrete type groups must be visible immediately, even when the original native disclosure checkbox is unchecked and the group has `display:none` inline. Category/type names must be 44px-tall links using their original destinations. The fixture's Film group must contain separately clickable HUN HD and ENG HD links. Verify a click reaches the exact `tipus` query rather than the broad category. Type checkboxes must still run their native handlers and remain in the original form. Hide filters and verify search stays visible. Deactivate and verify original group visibility and controls return.
5. Select a sort field and direction, then apply. Verify the URL retains `tags=drama`, sets `miszerint` and `hogyan`, and clears `oldal`. Check previous/next pagination, the last-page boundary, and the additional page links. Existing links provide query context.
6. Expand and collapse via the original torrent title. Its `aria-expanded` and `aria-controls` must track the native panel. Enter and Space must also trigger expansion. Use `Add row` and verify one summary/date block and one original bookmark are present in the new row, without duplicate controls. Open a bookmark by touch/click and keyboard, confirming the original handler still runs.
7. With aNi present, the highlighter and torrent-hide icon must be completely hidden only in mobile mode. The hide icon's place must show one clickable IMDb score using the existing IMDb destination and computed color, including later inline-style/class color changes; the duplicate subtitle score must be hidden. Use `IMDb color` in the fixture to check a subsequent aNi color change. Rows without an IMDb score must not reserve an empty icon column. All original aNi controls and handlers must return unchanged on desktop. “Új”, “Ellenőrzött”, and “Ellenőrizetlen” badges and original icons must be absent on mobile, including on an unchecked row. Bookmarks must work in both variants.
8. Open a bookmark dialog. Focus must enter the name field, Tab/Shift+Tab must remain inside the dialog, and Escape or `Bezárás` must use the native cancel action, unlock page scrolling, and return focus to the opener. No save action should fire during dismissal.
   On mobile the category select must be hidden and each visible option must have a wrapping, at least 44px-tall button. Initially Games must be pressed. Click Filmek and verify only Filmek is pressed, the original select value is `film`, and its native change handler runs once; selection must not save. Mentés must read that same value. Disabled/hidden options must remain unavailable. `Kategória betöltése` must add a new usable button without duplicates, and `Eredeti választás` must synchronize Games. Enter/Space must choose categories. At 320px, long category names must wrap without overflow. Switch to Desktop with the dialog open: the original select must return with the current value and the category buttons must disappear. Re-enable mobile and reopen the dialog to check there are no duplicates.
9. Open `/torrents.php?action=details&comments=1` for synthetic multi-comment coverage. At 320px and 390px, comment avatars must be hidden, text must fill the available width, and long links/quotes must wrap without horizontal overflow. Deactivate mobile mode and verify the original avatars and columns return.

The fixture is a regression aid, not a replacement for testing the live nCore page: themes, other extensions, and future site markup can differ.
